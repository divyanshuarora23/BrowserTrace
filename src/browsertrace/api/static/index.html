Limitations

Findings are investigative leads produced by automated rules, not proof of wrongdoing. Each must be verified against its linked source events before being relied on. Rules can miss activity (false negatives) and can flag innocent activity (false positives); off-hours activity, file-sharing visits and similar signals are context, not conclusions. Timestamps are only as accurate as the browser's own clock at the time of the event.
